## Prommt:

Je veux créer une présentation en **Markdown** à partir du contenu fourni sur mon projet technique : une plateforme de code destinée aux débutants de niveau A1.
La présentation doit garder la même structure et les mêmes parties :
- Présentation de mon projet technique.
- Sujet du projet.
- Objectif du projet.
- Fonctionnalités de la plateforme.
- Tâches du projet.
- Langages de programmation.
- Exemple de code.
- Ressources utiles.
- Conclusion.
**Consignes :**
- Utiliser un français simple de niveau A1.
- Améliorer la partie « Sujet du projet » pour présenter précisément le projet.
- Garder des phrases courtes et faciles à comprendre.
- Utiliser les éléments Markdown : titres, paragraphes, gras, italique, barré, listes, listes de tâches, liens, tableaux, code, blocs de code, citations et lignes horizontales.
- Ajouter des images pertinentes avec la syntaxe Markdown.
- Ne pas supprimer les parties de la présentation.
- Organiser le contenu en diapositives Marp.
- Fournir le code Markdown complet, prêt à copier dans un fichier `.md`.
