# 01 — Introduction

## Pourquoi structurer une présentation ?

Une bonne présentation permet de :

- Organiser les idées.
- Faciliter la compréhension.
- Captiver l'attention du public.
- Présenter le travail de manière professionnelle.


---

# 02 — Le plan général

## Les 5 parties essentielles

1. **Page de garde** — Identifier le sujet.
2. **Introduction** — Présenter le contexte et les objectifs.
3. **Développement** — Expliquer le travail réalisé.
4. **Conclusion** — Résumer les résultats.
5. **Sources** — Mentionner les références utilisées.

---

# 03 — Page de garde

## Présenter les informations essentielles

- Titre de la présentation.
- Nom et prénom de l'apprenant.
- Nom de l'encadrant.
- Logo de l'établissement.
- Date ou période de réalisation.

---

# 04 — Introduction

## Présenter le sujet

L'introduction doit répondre à quatre questions :

- **Quoi ?** Quel est le sujet ?
- **Pourquoi ?** Quel est le besoin ?
- **Dans quel contexte ?** Quelle est la situation ?
- **Pour quoi faire ?** Quels sont les objectifs ?

> L'objectif est de donner au public une vision globale du travail.

---

# 05 — Développement

## Présenter le travail réalisé

C'est la partie principale de la présentation.

Elle contient :

- Présentation du sujet.
- Étapes de réalisation.
- Méthodes et outils utilisés.
- Fonctionnalités développées.
- Résultats obtenus.

---

# 06 — Conclusion

## Terminer efficacement

La conclusion permet de présenter :

- Un résumé du travail.
- Les résultats obtenus.
- Les compétences acquises.
- Les difficultés surmontées.
- Les perspectives d'amélioration.

**Objectif :** laisser une impression positive au public.

---

# 07 — Sources

## Mentionner les références

Lorsque cela est nécessaire, ajouter :

- Sites web consultés.
- Documentation technique.
- Articles et tutoriels.
- Livres et supports de formation.

Exemples :

- MDN Web Docs
- PHP Documentation
- W3Schools

---
