# SKILLS

## Présentation professionnelle

**Préparer • Organiser • Présenter**

---

# 01 — Objectif

- Préparer une présentation.
- Organiser les idées.
- Créer des diapositives.
- Présenter clairement un travail.

---

# 02 — Plan général

1. Page de garde.
2. Introduction.
3. Développement.
4. Conclusion.
5. Sources.

---

# 03 — Page de garde

- Titre du sujet.
- Nom de l'apprenant.
- Nom de l'encadrant.
- Logos demandés.

---

# 04 — Introduction

- Présenter le sujet.
- Expliquer le contexte.
- Identifier le besoin.
- Présenter l'objectif.

---

# 05 — Développement

- Présenter les informations importantes.
- Expliquer les étapes du travail.
- Utiliser des listes simples.
- Ajouter des images et des schémas.

---

# 06 — Conclusion

- Résumer le travail.
- Présenter les résultats.
- Expliquer les difficultés.
- Présenter les apprentissages.

---

# 07 — Sources

- Sites web.
- Documentation.
- Articles.
- Livres et références.

*Ajouter les sources lorsque c'est nécessaire.*

---

# 08 — Exemples de présentations

**01 — Lab**

Objectif • Étapes • Pratique • Résultat

**02 — Veille technologique**

Technologie • Fonctionnement • Avantages • Actualités

---

# 09 — Autres présentations

**03 — Projet technique**

Besoin • Solution • Conception • Réalisation

**04 — Projet fil rouge**

Problématique • Équipe • Fonctionnalités • Résultats

---

# 10 — Règles de validation

- Page de garde complète.
- Introduction claire.
- Développement organisé.
- Conclusion avec résultats.
- Sources si nécessaire.

---

# 11 — Règles de style

- Design simple et professionnel.
- Couleurs harmonieuses.
- Polices lisibles.
- Images adaptées.
- Titres courts.
- Même style dans toutes les diapositives.

---

# 12 — Règle d'apprentissage

# ZÉRO TEXTE

**Moins de texte • Plus de visuels • Plus d'explication orale**

---

# 13 — Comment appliquer Zéro Texte ?

- Éviter les longs paragraphes.
- Utiliser des mots-clés.
- Ajouter des icônes.
- Utiliser des images.
- Présenter les idées oralement.

---

# 14 — Compétences à développer

- Organiser les idées.
- Créer des diapositives.
- Choisir les bons visuels.
- Parler clairement.
- Gérer le temps.
- Répondre aux questions.
